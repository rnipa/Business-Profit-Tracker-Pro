BUSINESS PROFIT TRACKER PRO — FULL PWA DESKTOP PACKAGE

RECOMMENDED:
1. Extract this ZIP to a permanent folder.
2. Double-click "Start Business Profit Tracker.bat".
3. Chrome/Edge will open the app at http://127.0.0.1:8765.
4. Use the "Install App" prompt or browser's Install App option.
5. After installation, launch "Profit Tracker" from the Windows Start Menu/Desktop.
6. The app can work offline after its assets have been cached.

IMPORTANT DATA SAFETY:
- Profit and expense data are stored locally in the browser profile.
- The app includes encrypted local-storage handling from the previous version.
- Settings > Backup should be used regularly.
- Keep backup JSON files in a safe location.
- Do not delete the browser profile that contains the app data unless you have a backup.

PWA NOTE:
A browser cannot reliably install a PWA from a file:// HTML file. The included BAT launcher starts a local web server on 127.0.0.1 so Chrome/Edge can use the normal PWA install mechanism.
